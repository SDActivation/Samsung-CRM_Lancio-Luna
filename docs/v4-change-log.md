## External capabilities — explicitly incomplete

**Live assistant is not connected.** No authorized model runtime, model configuration or spend policy was supplied. The server responds unavailable and the UI labels it `Assistant not connected`. Read-only evidence functions exist, but an eve agent runtime is not installed/provisioned or represented as operational. eve 0.88.0 packaged documentation was inspected for the future runtime; no personal subscription or app login is treated as backend model access. Free-question retrieval/tool/model responses and live copy proposals are not verified.

**Live image generation is not connected.** The built-in authoring tool created the initial asset, not a runtime service for the published app. The Generate control checks the same-origin endpoint and explicitly returns no job/no charge; it does not simulate generation. A reference-capable server provider, authorized spend limits, durable job/asset persistence and actual runtime generation/editing adapter still need implementation and verification once a service is selected. Existing master remains available without external services.

**Marketing handoff stays mock/manual.** No real Stensul transfer, customer send, audience upload or campaign scheduling occurs. Receipts are browser-local demonstrations, not authoritative vendor status.

Do not call the full specification 2.3 complete: core functionality and authoring artifact can be demonstrated, while these independently configured live capabilities remain unavailable. No new paid service, external agent runtime or hidden credentials have been activated.
