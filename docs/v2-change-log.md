# V2 implementation changes

The user supplied specification 2.0, then explicitly requested a version without credentials or login for now. This overrides section 8.1. No account, secret, password, client login flag or authentication service is included. The supplied private Markdown had its two bootstrap values removed locally and is never committed or exported.

The S1–S5 model and 5×5×4 quota are retired. The immutable source catalogue contains all 100 original deck definitions, their original IDs, family labels, selection criteria, tone/content, channel/CTA and source slides. Twelve dimensions, six lenses and six original showcase transcriptions are separately versioned JSON inputs. No original private brief or presentation is distributed.

Resolved rules and explicit recipe mappings are separate. Memberships are multi-match with unknown states. The default dataset contains 10,000 synthetic contact/session profiles and 100 separate business accounts. Curated fixture memberships are openly labelled; no unprovided quantitative threshold becomes a Samsung policy. The source MC061 30-day window is distinguished from configurable demo contact caps.

Campaign phase, relationship journey and lifecycle are independent. Recipe selection is parametric, signature-deduplicated and coverage-aware. Requested target and actual candidates / selected / eligible / approved counts are separate. Insufficient pool produces an incomplete gap report, not duplicate creative.

Project Luna has a concept claim register. Commercial details and integrations remain unverified; no price or offer is invented. Concept-reference mode excludes simulated purchase recipes. RFP launch simulation includes labelled mock conversion / activation. Authorized product assets are still absent and a labelled visual slot replaces the former abstract orbs.

The six personas remain different people. Twelve curated proofs cover Members content, Members push, Shop push, email, web banner, landing, WhatsApp adaptation and a distinct B2B email placeholder. A separate persistent-customer journey processes visit / content / compatibility request / cart / purchase / delivery / setup / usage / opt-out with membership history and suppression.
